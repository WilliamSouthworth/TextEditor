# TextEditor

TextEditor is a web-based document accessibility and study tool being developed for our CS 321 Software Engineering project. The goal of the project is to allow users to upload PDF documents and interact with them in ways that make reading, studying, and reviewing documents easier.

## Project Goals

The application is planned to support features such as:

- Uploading PDF documents
- Viewing PDFs in the browser
- Highlighting important text
- Collecting highlighted text
- Exporting highlighted content into a separate document
- Text-to-speech playback
- Readability and accessibility options
- Adjustable font size and spacing
- Dyslexia-friendly reading options

The project will initially focus on PDF files. Support for additional document formats may be considered later.

## Minimum Viable Product

For the MVP, we plan to focus on the following core features:

1. Upload a PDF
2. Display the PDF to the user
3. Allow users to highlight or select important text
4. Store or display selected highlights
5. Provide text-to-speech functionality
6. Export selected/highlighted text

## Technology Stack

The current planned technologies include:

- **Python** - Main backend programming language
- **Flask** - Web application framework
- **HTML/CSS** - User interface
- **JavaScript** - Client-side interaction
- **PyMuPDF** - PDF processing and text extraction
- **PDF.js** - PDF display and browser interaction
- **Web Speech API** - Text-to-speech functionality
- **Git/GitHub** - Version control and team collaboration
